# Guess My Number 🎯

**Guess My Number** is a fun and interactive number-guessing game built with **React Native**. The app challenges users to think logically and test their luck while the phone tries to guess the number the user has in mind.

## 📱 Features

- 🤖 The app guesses the number you're thinking of between a defined range.
- 🔼 You provide hints (higher/lower), and the app adjusts its guesses accordingly.
- 🧠 Basic logic and random number generation to simulate a guessing algorithm.
- 🎮 Simple and clean user interface for smooth gameplay.
- 📊 Summary screen at the end to show attempts taken.

## 🛠️ Technologies Used

- **React Native**
- **JavaScript (ES6+)**
- **React Hooks**
- **Custom Components**

## 🚀 Getting Started

### Prerequisites

- Node.js
- React Native CLI
- Android Studio / Xcode (for simulator/emulator)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Triankit/guessNumber.git
   cd guessNumber
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npx react-native start
   ```

4. Run the app:

   - For Android:
     ```bash
     npx react-native run-android
     ```

   - For iOS:
     ```bash
     npx react-native run-ios
     ```
